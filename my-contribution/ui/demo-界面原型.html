电子衣柜 · 界面原型

核心只有一个：拿主意。
衣柜和广场是配套，抽屉里已经降级。
四个板块点进去，各有一个 3 秒体感。

四个板块 = 四种交互范式

抽取式
塔罗牌 / 刮刮乐 / 盲盒
放弃控制权，翻牌 · 刮开
调节式
能量条 / 社交电量
拖滑块，连续值，实时反馈
选择式
身份扮演 / 场景 / MBTI
点卡片，明确的主动决策
输入式
一句话日记 / 水晶能量
打一句话，下面自己匹配
