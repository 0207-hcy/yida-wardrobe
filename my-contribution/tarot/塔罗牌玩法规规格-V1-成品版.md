## 1. 一句话定义与定位

> **抽三张牌，让牌替你定下今天的方向。**

这个玩法不是问用户"你今天想穿什么"，而是反过来：

> **我今天不想做决定，你替我拿一个主意。**

用户唯一要做的动作就是**抽牌**：

1. 滑动牌轮找牌
2. 点中间那张抽走
3. 重复三次

剩下的全部交给牌 —— 牌给出方向，用户负责接收。

## 3. 核心口径（8 条定稿）

| # | 项目 | 定稿 |
|---|---|---|
| 1 | 抽牌数 | **3 张**，随机不重复 |
| 2 | 牌库 | **大阿尔卡纳 22 张** |
| 3 | 每张读法 | **一句**（正位取 `up`，逆位取 `rev`） |
| 4 | 正逆位 | **正位 + 逆位都要**；逆位概率 **38%**；**全部正导向** |
| 5 | 三张顺序 | ① 现在的你 → ② 正在发生的变化 → ③ 今天给你的提醒 |
| 6 | 逆位框架 | **能量向内**（正位＝能量往外显性；逆位＝能量往内隐性），两者都只读成一种「态度」 |
| 7 | 输出 | **整页只输出一段话**，末尾一句温柔总结 |
| 8 | 布局 | **最上方预留「今日穿搭」空位**（本期留空） |

**关于逆位概率为什么是 38%**：标准塔罗正逆位是 50/50，但本产品是"穿搭决策"而不是占卜 —— 逆位句全部是"往内收"的语气，50% 时"三张全逆位"占 12.5%，整段话的下压感偏重。下调到 38% 后：

| 逆位概率 | 三张全正位 | 恰好 1 张逆位 | 恰好 2 张逆位 | 三张全逆位 |
|---|---|---|---|---|
| 50%（标准塔罗） | 12.5% | 37.5% | 37.5% | 12.5% |
| **38%（本产品）** | **23.8%** | **43.8%** | **26.9%** | **5.5%** |

最常出现的画面变成**"两张正位 + 一张逆位"**，逆位回到"少数派提醒"的位置。

## 4. 三张牌的位置角色

| 位置 | 名称 | 回答的问题 |
|---|---|---|
| 第 1 张 | **现在的你** | 你今天处在什么状态 |
| 第 2 张 | **正在发生的变化** | 有什么正在松动 / 转向 |
| 第 3 张 | **今天给你的提醒** | 今天可以怎么对自己 |

三张牌**有顺序、讲一个今天的故事** —— 不是三张互不相干的牌。

> 位置只决定**文案的排列顺序**，不改变牌本身的含义；同一张牌出现在不同位置时，读起来仍然连贯。

## 5. 正位 / 逆位规则

### 5.1 抽取规则

- 每张牌抽出时**独立判定**，逆位概率 **38%**
- 判定与牌本身无关、与用户衣柜无关 —— **纯随机**

### 5.2 读法框架

| 状态 | 能量方向 | 例子（愚者） |
|---|---|---|
| **正位** | 能量往**外**（显性、当下就能做） | "你心里那点想出发的念头，这会儿特别活。" |
| **逆位** | 能量往**内**（隐性、先在心里过一遍） | "你今天更想把这点心思先收着，慢慢想清楚再动。" |

**逆位不是负面。** 逆位只是把同一股能量转向内部，读起来是"先在心里走一遍"，不是"做不到"。

### 5.3 凶牌正向化

传统塔罗中的凶牌（死神 / 塔 / 恶魔 / 月亮）在本玩法里**不给坏结果**，只给今天的「态度」：

| 牌 | 传统印象 | 本玩法的读法 |
|---|---|---|
| 死神 | 结束、损失 | "有些东西该翻篇了，放手其实是腾出手。" |
| 塔 | 崩塌、灾祸 | "有东西松了，其实它本来就不太稳。" |
| 恶魔 | 诱惑、束缚 | "有点想放纵一下，承认它也没什么关系。" |
| 月亮 | 迷惘、不安 | "看不清也没关系，慢慢走就对了。" |

**原则**：只读成"今天可以怎么理解这件事"，绝不预测吉凶。

### 5.4 语气红线

- ✅ 像一位**有点神秘、但很懂你**的朋友
- ❌ 不做命运预言（"你今天一定会遇到贵人"）
- ❌ 不做恐吓（"穿红色今天会倒霉"）
- ❌ 不做负面心理诊断（"你内心其实非常焦虑"）

## 6. 输出形式：统一一段话

### 6.1 拼段规则

整页**只输出一段话**，由四句组成：

```
第 1 张（现在的你）· 取一句
＋ 第 2 张（正在发生的变化）· 取一句
＋ 第 3 张（今天给你的提醒）· 取一句
＋ 今日总结 · 从 8 句池随机取一句
────────────────────────────
四句直接连成一段
```

**不逐张单独解读**，也不分成"解牌 + 总结"两块。抽出来的三句话**按位置顺序直接首尾相接**，末尾接一句温柔总结。

### 6.2 开场词刻意错落

22 张牌的句子开头**刻意做了错落**（"你今天更想…／其实你更想…／你更想…／现在你更想…"），避免三句连读像复读机。

### 6.3 完整样例

假设抽到 **魔术师·正 / 倒吊人·逆 / 星星·正**：

> 你确实有把话讲清楚的底气。你今天更想先不急着下决定，让事情再放一放。不必用力，光会自己照过来。所以今天，先对自己温柔一点，剩下的交给时间。

前三句来自三张牌、按位置顺序连起来，**最后一句是今日总结**。

### 6.4 今日总结句池（8 句）

1. 所以今天，先对自己温柔一点，剩下的交给时间。
2. 所以今天，不用急着完美，走一步算一步就好。
3. 所以今天，允许自己慢一点，你已经在路上了。
4. 所以今天，先照顾好自己，别的都会跟上来。
5. 所以今天，信一点直觉，也信一点自己。
6. 所以今天，把心放宽些，会好的。
7. 所以今天，做完想做的，剩下的明天再说。
8. 所以今天，你说了算，这样就很好。

## 7. 交互规格 A｜抽牌页（竖弧牌轮）

### 7.1 页面结构（从上到下）

| 顺序 | 元素 | 内容 |
|---|---|---|
| 1 | 标题 `h1` | "抽第 N 张牌" → 抽满后变为"三张抽好了" |
| 2 | 副标题 | "上下滑转动牌轮，点中间亮起来的那张抽走。" |
| 3 | 进度 | "已抽 N / 3 张" |
| 4 | **牌轮区** | 高 520px，深色圆角底，`touch-action:none` |
| 5 | 底部提示 | "牌轮里 22 张大阿卡纳 · 抽满三张直接出解读" |

### 7.2 牌轮形态：竖弧

- **不是一个完整的圆**，而是**圆的其中一段**：牌沿着一条**竖弧**从屏幕上排到屏下
- 弧线整体**朝左鼓**，转动的**轴在屏幕右外侧（不可见）**
- 牌**横放**（宽 > 高），并且**沿半径朝外指** —— 像折扇的一根根扇骨
- 22 张牌**互相叠压**，每张只露出约三分之一

### 7.3 当前牌（候选牌）

- 位置：**正对指针**（弧线最左端、屏幕中部）
- 表现：**金色描边 + 金色光晕**，层级最高
- 指针：候选牌中心有一个**金色小圆点**

### 7.4 手势

| 动作 | 行为 |
|---|---|
| **上下滑** | 沿着竖弧转动牌轮，手指跟手；转经新的牌时短振动（8ms） |
| **松手** | 自动**吸附**到最近的牌位（弹性缓动），回弹时短振动（6ms） |
| **点击**（未拖动） | 抽走当前金色高亮的那张；三连振动（12/42/18ms） |

> 拖动超过 6° 后松手，**不会误触抽牌**。

### 7.5 抽牌后的行为

1. 该牌变淡（不再可选）
2. 进度 +1，标题变为"抽第 N+1 张牌"
3. **自动转到下一张未抽的牌**
4. 抽满 3 张 → 标题"三张抽好了" → **420ms 后自动进入解读页**

### 7.6 没有的环节

- ❌ 没有洗牌
- ❌ 没有切牌
- ❌ 没有"抽完三张"的中间展示页
- ❌ 没有牌阵选择

进入玩法**就是选牌**，一步到位。

### 7.7 30 秒验证步骤

1. 双击 `web/tarot/index.html`（任意浏览器，**无需服务器**）
2. 在牌轮上**上下滑** → 牌跟着转，中间那张始终金色高亮
3. **连点中间 3 次** → 自动跳转解读页

## 8. 交互规格 B｜解读页

### 8.1 页面结构（从上到下）

| 顺序 | 元素 | 内容 |
|---|---|---|
| 1 | 标题 | "牌给你的话" |
| 2 | 副标题 | "三张牌，讲一个只属于今天的故事。" |
| 3 | **今日穿搭预留位** | 虚线框，文案"预留位 · 本期不做，先空着" |
| 4 | **三张牌** | 折扇式堆叠 |
| 5 | 当前位置信息 | "① 现在的你 · 正位" + 牌名 + 关键词 |
| 6 | **一段话** | 统一输出（见第 6 节） |
| 7 | 按钮 | "再抽一次" |

### 8.2 今日穿搭预留位（硬约束）

> **页面最上方必须留出「今日穿搭」的位置。**

原设计层级是"上＝今日穿搭、下＝解读"。本期不做穿搭，但**位置和层级必须占好**，后续接上推荐结果时不返工。

### 8.3 三张牌的展示：折扇式

- 三张牌**堆叠成一把折扇**（中心一张在前，左右各一张在后，各偏转 11°）
- **左右滑** 或 **点击某张** → 切换查看，被选中的牌来到最前
- 切换时短振动
- 逆位的牌在**右上角标「逆」**

### 8.4 位置信息

当前在前的那张牌，下方实时显示：

```
① 现在的你 · 正位
愚者
出发 · 自由 · 轻装上阵
```

## 9. 状态流转

只有 **2 个界面状态**（比常规少一屏）：

```
State 01｜抽牌页
  ├ 进入即选牌（无洗牌、无切牌）
  ├ 已抽 0/3 → 1/3 → 2/3
  └ 抽满 3 张
        ↓（420ms 自动跳转）
State 02｜解读页
  ├ 今日穿搭预留位
  ├ 三张折扇牌
  ├ 统一一段话
  └ 「再抽一次」→ 回到 State 01
```

## 10. 数据规格

### 10.1 字段定义

| 字段 | 类型 | 含义 |
|---|---|---|
| `no` | string | 罗马数字编号（`0`–`XXI`） |
| `cn` | string | 中文名 |
| `en` | string | 英文名 |
| `kw` | string[3] | 卡面关键词（2–3 个） |
| `up` | string | **正位**一句 |
| `rev` | string | **逆位**一句 |

外层另有：

| 字段 | 含义 |
|---|---|
| `summaries` | 今日总结句池（8 句），末尾随机取一 |
| `_meta` | 口径说明（抽牌规则、拼段规则、语气） |

### 10.2 数据约束

- 编码 **UTF-8**，无尾逗号，可被 `json.load` 直接解析
- 单文件大小 ~7KB
- 全部文案**自己写死**，运行时不需要 AI、不需要联网

### 10.3 内容统计

- 22 张 × 2（正位 + 逆位）＝ **44 条牌面文案**
- ＋ 8 条今日总结 ＝ **52 条文案**

## 11. 二次操作

本期只提供**一个**：

| 操作 | 行为 |
|---|---|
| **再抽一次** | 清空已抽的牌，重新随机，回到抽牌页 |

> "换一件 / 换一套"属于结果页操作，依赖推荐引擎，**本期不做**。

## 12. 边界与异常

| 场景 | 处理 |
|---|---|
| 抽过的牌 | 不会再次出现（同一局内 3 张互不重复） |
| 三张牌文案互相冲突 | **不视为错误** —— 三张牌本来就是"三个侧面"，各说各的 |
| 连续抽到三张逆位 | 不特殊处理（概率 5.5%），照常拼段 |
| 抽到凶牌 | 按 5.3 正向化，不给坏结果 |
| 用户反复"再抽一次" | 允许，不做限制（本期无成本） |
| 衣橱里没有对应单品 | **与本期无关** —— 本期不接穿搭 |
| 天气 / 场合 | **与本期无关** —— 后续接引擎时再引入优先级 |

## 13. 视觉与动效要点

### 13.1 视觉

- 牌面：**深紫渐变**（`#4A4196 → #2C2566`），细紫描边
- 候选牌：**金色描边 + 金色光晕**（`#FFC861`）
- 牌轮区：深色圆角底，中心带一层淡淡的紫色光晕
- 整体风格：**神秘但不阴森** —— 紫色系、留白足

### 13.2 动效

| 动作 | 效果 |
|---|---|
| 转轮 | 跟手；松手后弹性吸附（`cubic-bezier(.34,1.4,.5,1)`，380ms） |
| 抽走 | 短促三连振动 |
| 备用提示 | 转经新牌 / 回弹 / 切换折扇，各有不同时长的短振动 |
| 页面切换 | 从右侧滑入 280ms |

### 13.3 自适应

窗口不够大时，整个手机框**等比缩放**，保证完整可见（不会出现"标题被裁掉"）。
