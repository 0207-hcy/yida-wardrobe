# 塔罗子系统说明（v1）

> 落位：参赛仓库 `docs/content/tarot.md` ｜ 生成于 2026-09-25 22:55（**开赛后**，现场从零创作）

## 1. 这是什么

「无用之用：电子衣柜塔罗穿搭」里**塔罗牌板块**背后的独立子系统：用户抽三张牌 → 得到**一段话**。

**可单独打开运行**：单文件、零依赖、无任何外链，双击即跑；后续再嵌入主框架。

## 3. 玩法口径

- **牌库**：大阿尔卡纳 22 张
- **抽 3 张**，随机无放回
- **三个位置**（按抽取先后）：① 现在的你 → ② 正在发生的变化 → ③ 今天给你的提醒
- **正位 + 逆位都要，逆位概率 38%**（产品调优值：标准塔罗为 50%，这里下调，让逆位成为「少数派提醒」——三张全逆位仅 5.5%）
- **全部正导向**：不给坏结果、不预测吉凶
- **逆位框架 = 能量向内**：正位＝能量往外（显性），逆位＝能量往内（隐性）；两者都只读成一种「态度」

## 4. 输出形式：统一一段话

整页**只输出一段话**：

1. 三张牌各取一句（正位取 `up`、逆位取 `rev`）
2. **按位置顺序直接连成一段**
3. 末尾再接**一句「今日总结」**（从 8 句池随机取一）

不逐张单独解读，也不分成「解牌 + 总结」两块。

示例（魔术师·正 / 倒吊人·逆 / 星星·正）：

> 你确实有把话讲清楚的底气。你今天更想先不急着下决定，让事情再放一放。不必用力，光会自己照过来。所以今天，先对自己温柔一点，剩下的交给时间。

## 5. 两屏交互

**抽牌页**

- 22 张牌**横放**，沿一条**竖弧**排开（半径 280px，可见约整圆的 1/3；转动的轴在屏幕**右外侧**）
- 牌位间隔 9°，牌与牌**互相叠压**，每张只露一条
- **上下滑**转轮，松手吸附到整牌位
- **点中间金色高亮的那张**抽走
- 抽满 3 张**自动进解读页**；无洗牌、无切牌、无中间展示环节

**解读页**

- 最上方预留「**今日穿搭**」空位（虚线框，本期留空，位置与层级已占好，后续接上不返工）
- 中间三张牌**折扇式堆叠**，左右滑 / 点切换查看（正逆位在卡面右上角标「逆」）
- 下方即上面那段话
- 「再抽一次」可重开

## 6. 数据字段（`tarot-deck.json`）

| 字段 | 含义 |
|---|---|
| `no` | 罗马数字编号 0–XXI |
| `cn` / `en` | 中文名 / 英文名 |
| `kw` | 卡面关键词 2–3 个 |
| `up` | 正位一句 |
| `rev` | 逆位一句 |
| `summaries` | 今日总结句池（8 句），末尾随机取一 |

- 编码 UTF-8，无尾逗号，可被 `json.load` 直接解析
- 校对结果：22 张 × 2（正/逆）＋ 8 句 = **52 条文案**
- **开场词刻意错落**（你今天更想…／其实你更想…／你更想…），避免三句连读像复读机

## 7. 怎么验证（30 秒）

1. 双击 `web/tarot/index.html`（任意浏览器，**无需服务器**）
2. 在牌轮上**上下滑** → 牌跟着转，中间那张始终金色高亮
3. **连点中间 3 次** → 自动跳转解读页，应看到：上方「今日穿搭」预留位 → 三张折扇牌 → 一段话（末尾是「所以今天…」）
