## 二、塔罗牌子系统（技术部分）

| 项目 | 内容 |
|---|---|
| 牌库 | 大阿尔卡纳 22 张 × 正位 / 逆位 = 44 条文案，＋ 8 句今日总结 = **52 条**，全部写死、零联网 |
| 抽牌页 | 竖弧牌轮：弧半径 R=280px、牌位间隔 STEP=9°、牌尺寸 170×120、拖动灵敏度 0.16°/px；上下滑转动、松手弹性吸附、点中抽走 |
| 解读页 | 折扇式三张牌（偏转 11°）、顶部预留「今日穿搭」虚线位、统一一段话输出 |
| 逆位调优 | 标准塔罗 50% → 本产品 **38%**，使三张全逆位概率从 12.5% 降到 5.5%，逆位回归「少数派提醒」 |
| 语气红线 | 凶牌（死神/塔/恶魔/月亮）全部正向化，只给「今天的态度」，不预测吉凶 |
| 交付形态 | 单文件自包含、无外链、无依赖，`file://` 双击即跑；同路径版本化 V1.0（逆位 50%）→ V1.1（逆位 38%） |
| 工程规范 | 分支 `feat/lisiyu-tarot-subsystem` 12 个小步提交，每条附 `docs/commits/` 说明；PR #1 可合并、无冲突 |
